DASHBOARD V1.10.7 — ORGANISATION PERSONNALISABLE

Base : V1.10.6 fournie par l'utilisateur.

Nouveau bouton : « Organiser »
Pour chaque grand bloc :
- ↑ monter
- ↓ descendre
- ↔ changer la taille : normal → large → compact → normal
- × masquer/fermer

Les blocs masqués restent récupérables dans « Blocs masqués » en mode Organiser.
Le bouton « Réinitialiser » remet la disposition d'origine.

La disposition est mémorisée localement sur l'appareil/navigateur.
La synchronisation et la collecte des données n'ont pas été modifiées.
