DASHBOARD V1.12.5 — INTERVENTIONS OUVERTES

La case prend maintenant toutes les interventions de Pilotage V134 SAUF celles considérées fermées :
- Clôturé / Clôturée
- Terminé / Terminée
- Archivé / Archivée
- Annulé / Annulée
- Réalisé / Réalisée
- Résolu / Résolue
- Fermé / Fermée

Donc elle inclut notamment :
- À faire
- À qualifier
- Planifié
- En cours
- En attente
- etc.

Le drag & drop, le redimensionnement et la synchronisation restent inchangés.
