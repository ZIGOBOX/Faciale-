DASHBOARD V1.11.1 — TAILLE VERTICALE

Ajout demandé :
Chaque case peut maintenant changer de hauteur indépendamment.

En mode Organiser :
↑ MONTER
↓ DESCENDRE
↔ LARGEUR
↕ + HAUTEUR
↕ - HAUTEUR
× MASQUER

La hauteur possède plusieurs niveaux :
très compact / compact / normal / haut / très haut / grand / très grand.

La largeur et la hauteur sont mémorisées séparément dans le navigateur.
Aucune modification de la synchronisation ou des données Pilotage V134.
